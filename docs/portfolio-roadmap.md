# Data Analyst / MIS Portfolio Roadmap

This roadmap keeps the portfolio focused on demonstrable, honest work.

## Project standards

- State the business question and the tools used.
- Include dataset source and clearly label synthetic/sample data.
- Explain the cleaning steps, metrics, and assumptions.
- Add screenshots only after checking that they match the actual output.
- Provide reproducible run instructions and expected outputs.
- Never describe a query, script, or dashboard as tested until it has been run.

## Portfolio projects

| Project | Main tools | Evidence to include |
|---|---|---|
| MIS Monthly Reporting Automation | Excel | KPI formulas, variance analysis, dashboard |
| E-commerce Revenue & Customer Analysis | SQL | Query files, business questions, verified results |
| Operations & Inventory Dashboard | Power BI | PBIX file, data model, screenshots |
| Data Cleaning & Quality Audit | Python, Pandas | Reusable script, validation summary |
| Retail Sales Analysis | Excel | Pivot tables, slicers, KPI dashboard |
| Retail Sales Performance Dashboard | Power BI | Report pages, date and category analysis |
| Customer Churn Analysis | Python, Pandas | Cleaning, exploratory analysis, findings |

## Before calling a project complete

- [ ] Files open successfully.
- [ ] Formulas, queries, or scripts have been tested.
- [ ] README explains how to reproduce the work.
- [ ] Findings are supported by the dataset.
- [ ] Limitations and synthetic data are disclosed.
